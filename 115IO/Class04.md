#### Entry and Exit

#####      進入與退出

**國企 Wen-Bin Chuang**
**2026-09-14**

![bg right fit](./images/04102.jpg)



----

#### 進入

<style scoped>
section {
    font-size: 30px;
}
</style>

- `進入者`是指在新市場中從事生產和銷售產品的企業。 
- 企業進入的行為通過以下兩種方式對`既存企業`構成威脅：    
  - 侵蝕既存企業的`市場份額`；    
  - 加劇行業內部競爭，導致`價格-成本利潤率（price-cost margin）`下降。

---

#### 新進入的形式 

<style scoped>
section {
    font-size: 30px;
}
</style>

- 企業進入新市場可採取不同形式：    
  - 進入者可能是`全新成立的企業`；
  - 也可能是已有的企業，通過`多元化`進入新的產品/市場。  

- 進入形式對分析`進入成本`以及既存企業的`策略反應`至關重要。

---

#### 退出的形式

<style scoped>
section {
    font-size: 30px;
}
</style>

- 企業可能`完全關閉`(Toys "R" Us（玩具反斗城） ,百視  達（Blockbuster)；
- 企業可能停止某個`特定產品或產品線`（例如 Sega 退出視頻遊戲硬體市場）；  
- 企業可能退出`某個特定的地理市場`（例如 Peugeot 退出美國市場）。

---

#### 關於進入與退出的實證研究

<style scoped>
section {
    font-size: 30px;
}
</style>

- Dunne、Roberts 和 Samuelson（簡稱 DRS）對 美國各行業的進入與退出進行了研究，發現： 
  - 進入和退出在美國普遍`同時存在`；    
  - 新進入者（退出者）比既存企業規模更小；    
  - 大多數新進入者很快失敗，而存活者則迅速擴張；    
  - 不同行業的進入率和退出率存在差異。

- 在五年的時間內，典型行業經歷了30%至40%的`企業更替（turnover）` ；僅有5%至10%的進入者是多元化經營企業（diversifying firms）；
  - 鼓勵進入的行業環境通常也會促進退出。

---

#### Barriers to Entry進入障礙(壁壘)

<style scoped>
section {
    font-size: 30px;
}
</style>

- 潛在的新進企業會將進入後的`沉沒成本`與進入後`預期利潤流的現值`進行比較。
  - 其中, 進入後的利潤取決於需求與成本狀況，以及進入市場後面對競爭的性質。

- 進入障礙(參進障礙)
  - 使既存企業能夠獲得經濟利潤，同時, 令新進入企業`無利可圖`的因素。  

- 進入障礙可分為兩類：    
  - **結構性障礙（自然優勢）**；    
  - **策略性障礙（既存企業為阻止進入而採取的行動）**。

---

#### 結構性的進入障礙

<style scoped>
section {
    font-size: 30px;
}
</style>

- 結構性的進入障礙存在於以下情形：  
  - 既存企業擁有`成本優勢`或`行銷優勢`
  - 既存企業受到有利的`政府政策`和`法規保護`。

- 常見結構性進入障礙包括：  
  - 既存企業控制**關鍵資源**；  
  - **規模經濟**與**範圍經濟**；  
  - 既存企業的`行銷優勢 （如品牌、客戶關係等）` 。

---

#### 關鍵資源的控制

<style scoped>
section {
    font-size: 30px;
}
</style>

- 某些投入要素的來源可能受**自然資源限制**，
  - 而既存企業可能已控制這些稀少資源；  
- **專利**可阻止競爭對手模仿企業的產品；  
- 既存企業可能嚴密保護難以被對手複製的**專有技術或訣竅**。

---

#### 規模經濟與範圍經濟 

<style scoped>
section {
    font-size: 30px;
}
</style>

- 若`規模經濟顯著`，潛在進入者可能面臨成本劣勢；  
- 既存企業對進入的戰略反應可能是進一步壓低價格，侵蝕進入者利潤；  
  - 若進入者成功進入，可能引發激烈的價格競爭。



- 範圍經濟方面：  
  - 進入者也可能因範圍經濟而處於成本劣勢；    
  - `生產上的範圍經濟`指在同一工廠生產多條產品線時產生的成本節約；    
  - `行銷上範圍經濟`指在進入者為建立品牌知名度所需承擔的前期`通路建設`成本。

---

#### 既存企業的行銷優勢 

<style scoped>
section {
    font-size: 30px;
}
</style>

- 既存企業可借助現有**品牌傘效應**，比新進入者更輕鬆地推出新產品； 
- **品牌傘效應**有助於既存企業更容易打通銷售管道
  - 例如：知名品牌更容易獲得貨架空間。
- 但需注意：  
  - 利用品牌聲譽並非沒有風險；  
  - 若新產品表現不佳，客戶不滿可能損害現有產品的品牌形象。

---

#### 策略性進入障礙

<style scoped>
section {
    font-size: 30px;
}
</style>

- 阻止進入的策略包括：`限制性定價`、`掠奪性定價`和`產能擴張`；  

- 這些策略要奏效，必須滿足：    
  - 既存企業作為壟斷者獲得的利潤高於作為(雙頭)壟斷者； 
  - 該策略能改變進入者對進入市場後**競爭狀況的預期**。

---

#### 限制性定價（Limit Pricing）

<style scoped>
section {
    font-size: 30px;
}
</style>

- 既存企業平時就會將`價格定得足夠低`，以阻止潛在進入者；  

- 限制性定價有兩種形式：    
  - `可競爭性`限制定價；    
  - 策略性限制定價。

---

#### 可競爭市場與進入威懾

<style scoped>
section {
    font-size: 30px;
}
</style>

- 若存在**打了就跑式進入**（即沉沒成本為零, 進出市場成本也為零），該市場即為`可競爭市場(contestable market)`； 
  - 賣冰的在店裡放上電影票

- 可競爭性市場可以使用的`限制定價` 
  - 既存企業擁有`過剩產能`，可將價格定在進入者邊際成本以下；  
  - 既存企業有能力以`低價`滿足全部市場需求。

---

#### 策略性的限制定價

<style scoped>
section {
    font-size: 26px;
}
</style>

- 新進入企業的產能有限或邊際成本遞增；  
- 限制性定價可能意味著既存企業`平時利潤犧牲` 或無法滿足全部市場需求；  
- 若進入者推斷進入市場後價格仍將很低，既存企業`平時低價`就可起到威懾作用。

#### 限制性定價是否理性？

- 在多期長期模型中，既存企業需在`每期都維持低價`，以阻止下一期的進入； 
- 既存企業`有可能`更願意接受雙頭壟斷，也不願長期以壟斷者身份`實施低價`的限制性定價。
- 進一步分析
  - 即使在兩期模型中，限制性定價均衡也不是子博弈精煉的；  
  - 潛在進入者可理性預期：進入後的價格不會低於均衡價格。

---

#### 掠奪性定價（Predatory Pricing）

<style scoped>
section {
    font-size: 27px;
}
</style>

- 掠奪性定價指既存企業`平時訂定壟斷價格`, 會在`看到新進入者進來市場之後`,將價格定在短期邊際成本以下，期望在競爭對手退出後通過壟斷利潤彌補損失；
  - **平時訂高價, 有人進來訂低價**, 直到新進者退出

- 掠奪性定價針對已進入的對手，而限制性定價針對潛在進入者。

---

#### 掠奪性定價是否理性？
<style scoped>
section {
    font-size: 27px;
}
</style>

- 若所有進入者都能準確預判既存企業的未來定價行為，掠奪性定價將無效； 
  - **連鎖店悖論**：儘管理性分析表明掠奪性定價難以威懾進入，但許多企業仍被認為在使用該策略。
  - 在`不確定性`的情況下，掠奪性定價可起到威懾作用；既存企業需建立`強硬`的聲譽。  

- 連鎖店悖論（Chain Store Paradox） 是由德國經濟學家、1994年諾貝爾經濟學獎得主萊因哈德·澤爾騰（Reinhard Selten） 在1978年提出
  - 一家大型連鎖企業，在 N 個不同的城鎮擁有壟斷地位。每個城鎮都有一個潛在的競爭者（我們稱之為進入者）。
  - 在現實世界的商業直覺中，連鎖店絕對應該在第1個或前幾個城鎮「不惜代價地迎戰」。雖然短期內會虧錢，但可以建立「我非常強硬」的聲譽（Reputation），從而嚇退後面所有城鎮的進入者，保住長期的壟斷利潤。
-  直覺認為該打仗，`邏輯`卻說不該打仗，這就是連鎖店悖論。 
----
<style scoped>
section {
    font-size: 27px;
}
</style>
- 進一步思考：  
  - 簡單經濟模型表明掠奪性定價是非理性的；  
  - 要麼企業行為非理性，要麼模型不完整；  
  - 引入不確定性和資訊不對稱的博弈論模型顯示，掠奪行為可以是理性的策略。

---

#### 限制性定價與掠奪行為理性的適用情形 

<style scoped>
section {
    font-size: 30px;
}
</style>

- 既存企業希望降低新進入者對進入市場後**價格的預期**； 
- 新進入者往往不瞭解既存企業的成本；  
- 在資訊不對稱情況下，既存企業的定價策略可改變進入者的預期。

---

#### 掠奪性定價與聲譽

<style scoped>
section {
    font-size: 25px;
}
</style>

- 當既存企業希望建立`強硬`聲譽時，掠奪性定價可威懾進入； 
  - 若既存企業不降價，其他挑戰者可能認為其`軟弱`而非`強硬`。

- `強硬`可能源於：  
  - 低成本；  
  - 非理性地追求市場份額；  
  - 存在進入者未知的其他競爭。  
  - 通過大幅降價，使進入者相信既存企業是`強硬`的。

- 一些知名企業在其競爭對手消失後，獲得了`強硬`的聲譽。
- 激進的市場份額策略包括：  
  - 公開宣佈市場份額目標；  
  - 以市場份額（而非利潤）為基礎獎勵管理者。

#### Standard Oil（1911）——教科書的起源

<style scoped>
section {
    font-size: 27px;
}
</style>

- 洛克斐勒被控在特定地區市場選擇性削價，擊敗獨立煉油業者，最終公司依《休曼法》被拆分。
- 但 1958 年 McGee 起質疑：證據其實無法證明 Standard Oil 真的從事掠奪，開始半世紀學術論戰。
- 地位：無論史實如何，它都是「掠奪性定價」這個概念的萬案之源

#### United States v. American Airlines（1999–2003）——「產能＋價格」雙刀流

- 1995–97 年 Vanguard、Sun Jet、Western Pacific 等`低成本航空`進入達拉斯/沃斯堡航線，AA 立刻加開班次＋大幅降價逼退對手。
- 對手退出後，票價隨即上漲（平均票價升至 88–123 美元），成為`「掠奪後回收」`的經典證據

---

#### Amazon vs. Diapers.com（2009–10）——平台時代的現代寓言

<style scoped>
section {
    font-size: 30px;
}
</style>

- 收購 Quidsi 被拒後，Amazon 發動尿布價格戰、折扣高達 30%，內部郵件顯示其目的在「壓制」新創對手。
  - 價格戰燒掉 Amazon 逾 1 億美元，最終 Quidsi 被迫出售。
- 諷刺續集：Amazon 於 2017 年關閉 Quidsi 全部業務——說明「掠奪→回收」的劇本也未必成真

#### Taiwan Case

<style scoped>
section {
    font-size: 30px;
}
</style>

- 藥品 1 元搶標案：原廠藥商進貨成本每顆約 12 元，卻以 1 元參標，封鎖第一個學名藥廠進入醫學中心的門檻，罰 300 萬元。
- 有線電視「0元看 1年」案：既有業者 C 只對新進業者 D 的訂戶 secretly 提供 0 元方案，價格低於平均變動成本，罰 250 萬元。


- **掠奪性定價是「用今天的虧損買明天的獨占**」——Standard Oil 是它的傳說，American Airlines 是它的教科書圖解, Amazon/Diapers.com 是平台時代的新爭議, 而台灣則選擇用「低價利誘」條款在掠奪門檻之下提前攔截。

#### 消耗戰（War of Attrition）

<style scoped>
section {
    font-size: 30px;
}
</style>

- 掠奪性定價`長期`可能演變為消耗戰；
  - 既存企業或新進企業 越相信自己能比對手堅持更久，就越願意發動並持續價格戰。
  - 企業（誰?）還可試圖說服對手自己更具持久力.
    - 例如，宣稱即使在價格戰期間仍在盈利。

- 早期無人退出，長期價格戰將損害全行業利益；  
-  即使勝出者，其狀況也可能不如從未發動價格戰。

---

#### 贏得消耗戰的關鍵 

<style scoped>
section {
    font-size: 30px;
}
</style>

- 企業越相信自己能比對手堅持更久，就越願意留在價格戰中；
- 面臨`高退出障礙`的企業更有條件參與價格戰；  
- 企業也可試圖讓對手相信自己能堅持更久
  - 例如：宣稱即使在價格戰中也資金充裕。

---

#### Excess Capacity過剩產能

<style scoped>
section {
    font-size: 30px;
}
</style>

- 美國製造業平均產能利用率約為80%；  
- 當產能擴張必須`一次性大幅投入`（lumpy）時，企業常因預期未來增長而持有過剩產能； 
- 需求暫時下滑也可能導致行業產能過剩，但這未必具有戰略意圖。

---

#### 過剩產能與進入威懾 

<style scoped>
section {
    font-size: 30px;
}
</style>

- 持有過剩產能的既存企業`可信地威脅`：一旦進入發生，將降價；  
- 擁有過剩產能的既存企業能以低成本擴大產量；  
- 即使進入者與既存企業資訊對稱，進入威懾仍可能發生。



- 過剩產能有效威懾進入的條件：  
  - 既存企業擁有可持續的成本優勢；  
  - 市場需求增長緩慢；  
  - 既存企業無法撤回過剩產能投資；  
  - 進入者並非試圖建立“強硬”聲譽的類型。

#### Judo Economics 柔道經濟學

<style scoped>
section {
    font-size: 30px;
}
</style>

- `新進入者`常見的策略：**柔道經濟學（Judo Economics）** 
  - 1983 年由經濟學家 Judith Gelman 與 Steven Salop 在〈Judo Economics: Capacity Limitation and Coupon Competition〉論文中創造。
  - 含義：小公司`借力打力`，把對手「龐大的體型」利用對手的優勢為自己服務，如同柔道以借力使力取勝。
  - 進入者通過表現出長期`無威脅`姿態，勸阻既存企業**不採取威懾策略**； 對既存企業而言，為打擊這樣一個“無害”進入者而承受巨大損失可能不值得。

- 1990 年代哈佛商學院 David Yoffie（與 Cusumano、Kwak）將其發展成完整的「柔道策略」框架，並以 Netscape 對微軟之戰作為經典詮釋

----

####  核心定價邏輯：Gelman–Salop 模型

<style scoped>
section {
    font-size: 30px;
}
</style>

- 經典例子：既存企業以 50 美元服務 10 個客戶。
  - 情境 A：挑戰者若想用 40 美元搶「整個市場」，在位者被迫跟價死戰，挑戰者終將被驅逐。
  - 情境 B：挑戰者若把產能限制到「只服務 1 個客戶」，在位者會發現維持 50 美元、保住其餘 9 個客戶更划算，於是理性地「容忍」其進入。

- 機制關鍵：在位者必須對全體客戶統一收費，跟價成本太高；小廠的可信自我限制，讓巨人的規模變成保護小廠的傘。

----

<style scoped>
section {
    font-size: 27px;
}
</style>

- **哈佛商學院** 教學案例同樣證明：進入者只瞄準`部分市場`並收低價，即使毫無附加價值也能賺錢；例如進入者以 150 美元取走一半客戶，在位者維持 200 美元而不跟降價
  - 實證研究：當進入者承諾`小市占`時，在位者確實較少發動價格、廣告或新品攻擊。
  - Kiwi 航空（最經典案例）：1992 年僅以兩架租賃飛機、只飛芝加哥–紐瓦克–奧蘭多單一航線進入市場；`限制可信`，大航空不視其為威脅，使其在紅海市場獲利。
- 反面教訓：Kiwi 於 1994 年擴張航線、放棄柔道限制，遭大公司價格戰反擊，1999 年底破產。
  - 其他業例：英國早餐穀片（Viota vs. Kellogg）、挪威水泥（Viking vs. Norcem）。
- 實證證據：進入者產能越小越容易被容忍；但若市場有「兩個」巨人（Bertrand 競爭），柔道限制大多失效，價格戰比率高達 76%

- 移動與`小狗策略`——在巨人「不要、不屑、不能吃」的 `niche` 長大
  - 「小狗策略」（puppy dog ploy，語出 Fudenberg & Tirole 1984）
  - Capital One 極度低調、不做產品發布會，悄悄長成美國最大信用卡發行商之一；
  - Palm 把手持裝置說成 PC 的「伴侶」而非「替代品」，暫時避开微軟全面攻擊。
  - 日系車 vs. 美國三大（1970s）／Nucor vs. 美國鋼鐵
    - 豐田們從小型省油車（低利潤邊陲）切入；三大車廠專注高利潤大車，理性容忍（打低價小車市場等於自噬利潤）。
    - Nucor 小型鋼廠從巨頭放棄的螺紋鋼起步，再一路爬上結構鋼、薄板。
      - 定價角度：小廠商在巨頭的「價格傘」下長大——Gelman–Salop 模型的現實版。

- Drypers 對寶鹼：P&G 在德州降下 2 美元優惠券轟炸，Drypers 乾脆打廣告宣布「P&G 優惠券可用於本公司產品」，把對手的攻勢變成自己的銷量。

- JVC（VHS）vs. Sony（Betamax）

  - Sony 的「技術優勢＋封閉生態」反成枷鎖，Betamax 出局。

- 小米 vs. Apple／三星（2011–15）

- 小廠付不起價格戰，所以主動限縮規模、躲在在位者的「價格傘」下；這正是賽局理論中「裝弱以避免被攻擊」的**小狗策略**在定價上的體現. 

- 適用條件：至少一個主導廠商＋可信的自我限制；巨人不止一家時柔道失效。

- 批評：柔道經濟學「把目標定得太低」——只求利基存活，無法贏下整個市場

- 柔道經濟學教「弱小者」如何讓巨人覺得「打你不划算」——定價上的關鍵動作，就是**可信地**限制自己的規模與野心。柔道的定價精髓不是「比巨人便宜」，而是讓巨人「跟不起、跟了會自噬、不跟又失血」——把對手的規模、利潤結構、通路與品牌，全部變成綁住他自己手上的繩子

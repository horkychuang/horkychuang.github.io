#### 維持競爭優勢 

<style scoped>
section {
    font-size: 30px;
}
</style>

- **長期**維持競爭優勢並非易事。
- 競爭對手可以`模仿`成功的模式。  
- 競爭對手可利用`新技術`、`新產品`和`新的商業模式`，削弱行業領導者的競爭優勢。
- 然而，一些企業（如可口可樂、戴爾電腦）成功長期維持其競爭優勢。而另一些企業則在競爭對手的壓力下逐漸喪失了競爭優勢(如 Nokia、Sony)

Why?

---

#### 盈利能力的持續性證據

<style scoped>
section {
    font-size: 30px;
}
</style>
- **傳統理論**上, `資產回報率（ROA）` 異常高的企業，其回報率會隨時間下降；資產回報率異常低的企業，其回報率會隨時間改善； 
  - `進入`、`模仿`和`價格競爭`最終會迫使經濟利潤趨於零；競爭力量會使資產回報率（ROA）趨近于資本成本；無論企業當前的盈利狀況如何，隨著時間推移，只要夠競爭, 其利潤終將向競爭性水準收斂。


----

#### 維持競爭優勢

<style scoped>
section {
    font-size: 30px;
}
</style>
Dennis Mueller’s study對美國製造企業的研究發現：


- 實際數據上, `高ROA`企業和`低ROA`企業並未趨同於一個共同的平均水準。意味著某些企業**競爭優勢** 能夠在競爭對手試圖複製或抵消它的努力下, 依然持續存在。

- 研究顯示: 可持續性可通過**兩種方式**實現：
  - 企業之間在`資源與能力`上存在持久差異；
  - 存在`隔離機制`（isolating mechanisms）
    - 類似於行業中的`進入障礙(壁壘)` ,保護企業的競爭優勢。

----

#### 企業資源基礎理論(Resource Based View, RBV)

<style scoped>
section {
    font-size: 30px;
}
</style>

- 企業資源基礎理論從 `資源與能力的異質性` 角度解釋持續競爭優勢。  

- 要支撐競爭優勢，**資源與能力** 必須具備以下特徵：    
  - **稀缺性**,    **不完全流動性**,    **無法在公開市場上獲得**
    - 對價值創造至關重要的 `稀缺資源與能力` 往往是 `不完全流動的`，無法在公開市場上輕易獲取。
  - 這些資源可能是不可交易的，也可能是**專屬關係資產（relationship-specific assets）**。
  

---

#### 隔離機制 (Isolating Mechanisms)

<style scoped>
section {
    font-size: 30px;
}
</style>

- `隔離機制`: 限制競爭對手`侵蝕`企業的競爭優勢。  

  - 對企業而言，隔離機制的作用相當於行業中的`進入障礙(壁壘)`。  

- 兩種主要類型的隔離機制包括：    
  - **模仿障礙**    
  - **先行者優勢**

---

#### 模仿障礙 

<style scoped>
section {
    font-size: 30px;
}
</style>

- 這些機制阻礙 `潛在進入者` 複製在位企業的資源和能力。  

- `五種`重要且常見的模仿障礙 包括：    
  - `法律限制`: 例如專利、版權以及政府監管
  - 對**投入品**或**客戶**的優先獲取管道  
  - 通過`垂直整合`、`長期合同`或`排他性交易條款`實現
  - `市場規模`與`規模經濟`    
  - `無形壁壘` 

----

#### 市場規模與規模經濟

<style scoped>
section {
    font-size: 27px;
}
</style>

- 當市場需求可由`單一生產者`滿足時（如專業產品市場），基於 **規模經濟** 形成的壁壘通常更有效。  

- 如果**市場增長**使進入變得有利可圖，基於規模經濟的壁壘可能隨之削弱。



#### 無形模仿壁壘

- 如果企業的優勢源於`獨特的組織能力`，則模仿壁壘往往是無形的。  

- 此類無形壁壘主要包括以下三種：    
  - 因果模糊性    
  - 歷史情境依賴    
  - 社會複雜性 

---

#### 因果模糊性 

<style scoped>
section {
    font-size: 27px;
}
</style>

- 當企業的成功源於`複雜`、`相互依賴`的內部資源（如`獨特的管理風格`、`員工協作模式`、`隱性知識`），外部競爭者很難拆解出哪些要素是關鍵。這種「黑箱效應」使模仿變得極其困難。

  - 因果模糊性本身也可能成為規模不經濟的來源，因為企業可能無法在不同工廠之間複製其成功經驗。


「因果模糊性（Causal Ambiguity）」就像一把**雙面刃**：

- **正面（隔離機制）**：因為競爭者看不懂你的「成功配方」，所以無法模仿，形成極強的護城河。
- **負面（規模不經濟）**：因為連企業自己都無法完全拆解這個「黑箱」，導致在跨國擴張、開設新廠或併購時，無法成功複製過去的輝煌，甚至因為強行複製而導致效率崩盤。

----

**因果模糊性（Causal Ambiguity）**為企業帶來了一個**策略兩難（Strategic Dilemma）**：

<style scoped>
section {
    font-size: 25px;
}
</style>

1. **若要防止模仿**：企業必須保持資源的複雜性與隱性化（維持黑箱）。
2. **若要追求成長**：企業必須將知識標準化、顯性化（SOP化），以便複製到新工廠或新市場。

**如何破解？** 成功的企業通常不會強行「複製黑箱」，而是採用以下策略來`避免規模不經濟`：

- **內部孵化（Internal Venturing）**：像蘋果或谷歌，當要進入新領域時，成立獨立的新部門，讓新的黑箱在內部自然生長，而不是把舊的黑箱強套上去。
- **保持適度規模（Optimal Scale）**：像西南航空或某些頂級精品品牌，主動放棄部分市場份額，將規模控制在「隱性文化與默契」能夠有效覆蓋的範圍內。
- **收購而非複製**：像迪士尼收購皮克斯，直接買下整個「黑箱團隊」並保持其獨立運作，而不是試圖把他們的基因抽出來注入自己體內。

#### 蘋果公司（Apple）的設計與整合哲學

<style scoped>
section {
    font-size: 27px;
}
</style>

- **因果模糊性（黑箱效應）：** 三星或華為可以買到與蘋果相同規格的螢幕、晶片，甚至模仿 iOS 的介面，但始終無法複製蘋果的「無縫體驗」。
  - 因為蘋果的成功源於賈伯斯留下的**跨部門極度咬合的整合能力**。在蘋果，`工業設計團隊`、`硬體工程團隊`、`軟體團隊`與`零售店體驗設計`是「同時且平行」開發的，這種**高度封閉、極度控制、依賴少數天才決策者品味**的協作模式，外部競爭者完全無法拆解，也無法從外部挖角來複製。
- **規模不經濟的爆發：** 這種黑箱模式在蘋果規模較小時威力無窮，但當蘋果成為市值數兆美元的巨頭時，這種「高度中央集權、依賴隱性默契」的模式開始遭遇瓶頸。
  - 例如在發展 **Apple TV+（串流媒體內容）** 或 **Apple Car（已終止的造車計畫）** 時，蘋果發現其封閉的整合文化與好萊塢的開放創意文化、或汽車產業的龐大供應鏈協作模式格格不入。
  - 強行將「蘋果黑箱」套用在需要大規模開放協作的領域，導致了極高的內部溝通成本與決策延遲，這就是典型的規模/範圍不經濟。

#### 豐田汽車（Toyota）與 TPS 生產系統的跨國困境

<style scoped>
section {
    font-size: 27px;
}
</style>

- **因果模糊性（黑箱效應）：** 全球車廠都曾花費巨資去研究豐田的「TPS（豐田生產方式）」，模仿其`「看板（Kanban）」`、`「Just-in-Time（及時生產）」`和`「零庫存」`，但所有人都失敗了。
  - 因為豐田真正的核心競爭力不是這些「看得見的工具」，而是**隱性知識與社會複雜性**：
  - 例如基層員工被賦予「隨時拉下停線繩（Andon Cord）」的權力、供應商之間長達數十年的信任與知識共享、以及深植於企業員工DNA的「持續改善（Kaizen）」文化。競爭者只學到了**形**，沒學到**神**。
- **規模不經濟的爆發：** 2000年代後期，豐田為了追求「全球第一」的規模，急速在美國、歐洲和中國擴張建廠。然而，TPS 高度依賴「人與人之間的默契」和「隱性文化傳承」。當工廠規模過大、跨國文化差異增加時，這種黑箱經驗**無法被標準化複製**到新工廠。 **結果：** 新工廠的品質管控失靈，導致 2009-2010 年爆發震驚全球的「大規模召回事件」（煞車與油門踏板問題）。這證明了當因果模糊性過高時，企業的擴張邊際成本會急劇上升，產生嚴重的規模不經濟。

#### 歷史情境依賴 

<style scoped>
section {
    font-size: 27px;
}
</style>

- 也常被稱為 **「路徑依賴」（Path Dependence）**。這是一個極具哲學意味的商業概念：
   - 企業今天的競爭力，是由`過去一連串`「獨特的選擇、偶然的機遇與歷史積累」所塑造的。

  - 獨特的能力可能與企業的發展歷史密不可分，難以被後來者複製。  

  - 對歷史情境的依賴可能限制企業的增長潛力。  

- 歷史依賴也可能意味著這些策略略僅在`有限時間內`有效。
- 「為什麼成功」的答案，常常寫在`過去的選擇`與**偶然**之中 

---

<style scoped>
section {
    font-size: 27px;
}
</style>

「歷史情境依賴」告訴我們一個殘酷的現實：**企業過去成功的基因，往往就是未來失敗的種子。**（即學者 Dorothy Leonard-Barton 提出的**核心剛性 Core Rigidity**）。

建議企業採取以下做法：

1. **建立「雙元性組織」（Ambidextrous Organization）：** 在維持核心業務（利用歷史優勢）的同時，必須成立`完全獨立的創新部門`（探索新情境），賦予其不同的 KPI、文化和資源，避免新業務被舊有的歷史慣性扼殺。
2. **定期进行「零基思考」（Zero-Based Thinking）：** 高層應定期質問：「如果我們今天才剛創立這家公司，沒有任何歷史包袱，我們會怎麼做現在的業務？」這有助於識別哪些是真正的核心能力，哪些只是歷史遺留下來的累贅。
3. **警惕「成功者的詛咒」：** 當一個策略在過去 10 年都非常成功時，管理者最該警惕的不是競爭者，而是「這個策略的`有效期限`是否已經到了」。

#### 百視達（Blockbuster）的「逾期罰款」包袱

<style scoped>
section {
    font-size: 27px;
}
</style>

- **歷史情境的積累：** 百視達在 1990 年代至 2000 年代初的絕對成功，建立在兩個歷史選擇上：
  - 大規模擴張實體店面，以及**高度依賴「影片逾期罰款」**（這曾佔其總利潤的 15% 以上）。這種模式在錄影帶/DVD 租賃的「歷史情境」下非常成功。
- **難以被後來者複製（正面）：** 當時的競爭者很難在短時間內複製百視達龐大的實體店面網絡和供應鏈。
- **限制增長與策略失效（負面）：** 當 Netflix 提出「無逾期罰款、郵寄租賃、後來轉向串流」的商業模式時，百視達其實有機會收購 Netflix 或跟進。
  - 但百視達**無法複製這個新模式**，因為他們的整個組織結構、KPI 考核、甚至營收預測，都**歷史性地依賴**於實體店面和逾期罰款。
  - 如果轉向無罰款模式，等於親手摧毀自己過去 20 年建立的獲利引擎（即「蠶食效應」Cannibalization）。
- **結果：** `過去`的成功路徑成為了`今天`的致命傷，百視達於 2010 年破產。

#### 柯達（Kodak）與數位相機的悖論

<style scoped>
section {
    font-size: 27px;
}
</style>

- **歷史情境的積累：** 柯達在`底片時代`的成功，建立在龐大的「化學製造資產」、「全球沖洗相片網絡」以及「剃刀與刀片（賣相機賺底片錢）」的商業模式上。
- **過去的選擇與偶然：** 鮮為人知的是，**世界上第一台數位相機其實是柯達工程師在 1975 年發明的**，柯達完全擁有這項技術。
- **策略僅在有限時間內有效：** 然而，柯達的管理層陷入了歷史依賴的盲點。
  - 他們過去的成功經驗告訴他們：「數位相機會蠶食我們高利潤的底片業務」。因為企業的資源分配、高層晉升、甚至企業認同感，都與「化學底片」的歷史情境綁定，他們選擇將數位技術雪藏，試圖延長底片時代的壽命。
- **結果：** 歷史情境改變（數位化浪潮），過去的成功公式瞬間失效，柯達最終因無法擺脫歷史包袱而走向衰敗。

#### 微軟（Microsoft）的「軟體授權」路徑依賴

<style scoped>
section {
    font-size: 27px;
}
</style>

- **歷史情境的積累：** 微軟過去 30 年的巨大成功，建立在「開發軟體 ➔ 銷售**永久授權（License）**」的商業模式上。這種模式利潤極高，塑造了微軟以「產品為中心」的銷售文化和組織架構。
- **限制增長潛力：** 當 2010 年代雲端運算（Cloud）和開源軟體崛起時，市場需要的是**訂閱制（SaaS）** 和**跨平台服務**。
  - 但微軟內部深受歷史依賴影響：銷售團隊習慣了一次性賣出高額授權，工程師習慣了將 Windows 視為封閉的搖錢樹。這導致微軟在行動裝置（Windows Phone）和早期雲端市場錯失良機，因為他們無法放棄歷史的獲利模式。
- **打破依賴：** 直到 2014 年 Satya Nadella 接任 CEO，他進行了痛苦的「零基思考」，強行將公司歷史依賴的「Windows 優先」策略，扭轉為「雲端優先（Cloud First）」，甚至將 Office 軟體開放給競爭對手蘋果的 iOS 系統。微軟花了近十年時間，才勉強擺脫了歷史情境的引力，重新獲得增長。

#### 社會複雜性

<style scoped>
section {
    font-size: 30px;
}
</style>

- 企業的競爭優勢如果建立在**人與人之間的互動、信任、文化與關係網絡**上，那麼競爭者就無法透過「購買設備」或「挖角單個人材」來複製它。 
  - 因為你無法買下一個團隊的`默契`，也無法用合約強制規定「信任」。

-  如果競爭優勢根植於`社會複雜的過程`，則很難被複製。 
  - 包括`管理者之間的互動`、`企業與供應商`及`客戶之間`複雜的社會關係網路，這些過程難以被外部觀察或模仿。
  - 即使這些複雜的社會互動被理解，也難以被模仿。
  

---

<style scoped>
section {
    font-size: 27px;
}
</style>
**社會複雜性**告訴我們：最堅固的競爭優勢，往往不是專利技術或獨家配方，而是「人與人之間如何協作」的無形網絡。對於管理者而言，這帶來兩個重要啟示：

1. **警惕「抄襲 SOP」的迷思：** 當企業看到競爭對手的成功做法時，不要只盯著表面的流程（SOP）或組織圖。必須深入思考：支撐這個流程的「社會規範、信任基礎與互動模式」是什麼？如果自身企業不具備這種社會土壤，盲目抄襲只會導致「橘逾淮為枳」。
2. **投資於「社會資本（Social Capital）」：** 企業應將建立內部信任、促進跨部門溝通、培養與供應商/客戶的長期夥伴關係，視為與投資研發（R&D）同等重要的戰略任務。因為技術會被迭代，但深厚的社會關係網絡是時間的朋友，極難被後來者超越。

#### 皮克斯（Pixar）的「智囊團（Braintrust）」機制

<style scoped>
section {
    font-size: 27px;
}
</style>

- **社會複雜性的體現：** 皮克斯能持續推出高品質動畫，核心在於其「智囊團」機制：
  - 一群資深導演和編劇定期聚會，對正在開發的電影進行「極度坦誠、甚至殘酷的批評」。關鍵在於，這種批評**沒有強制命令權，只有建議權**，且導演有權決定是否採納。這需要極高的「心理安全感（Psychological Safety）」，參與者必須深信批評是針對作品而非個人，且不會影響自己的職位。
- **即使理解也難以模仿的實證：** 2006 年迪士尼收購皮克斯後，迪士尼高層完全理解了「智囊團」的運作規則，並試圖將其複製到迪士尼動畫本部，以拯救當時陷入僵局的迪士尼動畫。 
  - **結果卻慘遭滑鐵盧。** 因為迪士尼原有的組織文化充滿了官僚層級、政治鬥爭和嚴格的績效考核。在這種社會環境下，員工不敢說真話，害怕得罪高層。
  - 結果，迪士尼的「智囊團」退化成了形式主義的「互相表揚大會」，完全失去了皮克斯那種銳利、建設性的批判力量。這完美印證了：**你可以複製會議的流程，但無法複製支撐該流程的社會互動規範。**

#### 諾德斯特龍（Nordstrom）的極致客戶服務

<style scoped>
section {
    font-size: 27px;
}
</style>

- **社會複雜性的體現：** 美國高端百貨`諾德斯特龍`以其「無條件退貨政策」和極致服務聞名（甚至有傳說員工接受客戶退還非該店銷售的輪胎）。
  - 這背後依賴的是一種微妙的社會複雜性：公司給予`第一線員工`極大的「自由裁量權（Discretion）」來解決客戶問題，這建立在**公司對員工的絕對信任**，以及**員工對公司的忠誠與責任感**之上。

- 為何難以模仿：許多競爭者（如 JCPenney 或梅西百貨）曾試圖模仿這種「授權員工取悅客戶」的策略。但由於這些公司內部缺乏長期的信任網絡，往往導致兩種失敗結果：

  1. 員工濫用權力，導致退貨成本暴增，公司被迫收緊政策。
  2. 管理層骨子裡不信任員工，表面授權，實則設置繁瑣的審批流程，導致員工無法及時解決客戶問題，服務體驗大打折扣。

#### 先發優勢 Early-Mover Advantage

<style scoped>
section {
    font-size: 30px;
}
</style>

先發優勢包含以下四種隔離機制：  

- 學習曲線  
  - 先行者通過`經驗累積` 降低成本，後進者難以追趕

- 聲譽與買家不確定性  
- 轉換成本  
- 網路效應

---

#### 聲譽與買家不確定性

<style scoped>
section {
    font-size: 30px;
}
</style>

- 對於`體驗型商品`，企業良好的品質聲譽可帶來顯著的先發優勢。  
  - `搜尋型商品（Search Good）`: 購買**前**就能評估其品質、特徵或價值的商品, 
  - `體驗型商品（Experience Good）`: 必須實際使用或消費**後**，才能判斷其品質好壞的商品

- `先驅品牌`能影響消費者**偏好的形成**，並將自身品牌屬性塑造為該產品類別的理想標準。

---

#### 轉換成本

<style scoped>
section {
    font-size: 27px;
}
</style>

在某些情況下，買家若`更換供應商`將產生顯著的轉換成本，例如：  

- 消費者在特定品牌上進行`專用性投資`（如學習使用某軟體)後，轉換品牌的成本很高；
  - 賣方累積了針對特定買家的知識（如銀行業務）；  
  - 顧客加入超市的忠誠計畫或航空公司的白金旅客計畫。



#### 網路效應


- 當顧客對產品的價值評估取決於使用該產品的其他`使用者數量`時，該產品即具有`網路效應`。  

- 實際網路的價值取決於已有用戶數量（如電話網絡、社交網路）；  

- 虛擬網路則源於互補品的使用（如軟體與個人電腦）。

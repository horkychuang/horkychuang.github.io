#### 企業行為的社會脈絡

<style scoped>
section {
    font-size: 30px;
}
</style>

- 企業做生意，不是只看冷冰冰的數字，而是要看它身處的 **「大環境規則（社會脈絡）」**。企業必須同時看懂 **「政府規定的明規則」**、**「同行默契的潛規則」**，並且處理好 **「對外的市場環境」** 與 **「對內的公司文化與權力」**, 這包含了政府規定的法律，以及同行之間心照不宣的「潛規則」。
- 企業的兩個生存戰場：
  - 外部（企業採取行動的脈絡）: 同一個市場裡，彼此的行為會互相影響
  - **內部**（管理者進行決策的脈絡）: `內部脈絡`是指管理者與員工在企業內部工作的政治與文化環境。。

---

#### 外部脈絡

<style scoped>
section {
    font-size: 27px;
}
</style>
- 企業`對外`的**社會脈絡**包含企業所受的**正式**與**非正式規範**。
  - 正式：由政府官員制定並執行
    - 企業在「市場」中與其他公司競爭、合作的環境。大家都在同一個市場裡混，彼此的行為會互相影響
  - 非正式：市場的文化與認知秩序
    - 市場的文化與認知秩序，是同行企業間的「共同價值觀與共識」
- 非正式規範源自於`產業內`企業間的共同價值觀與共識

-----

#### 內部脈絡

<style scoped>
section {
    font-size: 27px;
}
</style>

- `權力`與`文化`是內部脈絡的兩個主要面向。
- 正式結構`無法完全解釋`複雜組織的運作。

  - **為什麼需要它們？** 因為公司太複雜了，不能什麼事都寫進死板的「公司規定（正式結構）」裡。

- 通常，來自不同部門的管理者需要在沒有`正式規範`要求的情況下進行合作。當`正式控制`與`契約不可行`時，**權力與文化**在解決衝突方面扮演著重要角色。

  - 當不同部門需要合作，或是發生吵架（衝突）時，往往沒有明確的合約可以依循。這時候，靠的就是公司的 **「文化（大家習慣怎麼做事）」** 和 **「權力（誰說話比較有分量）」** 來解決問題。

#### 權力

<style scoped>
section {
    font-size: 27px;
}
</style>

- **真正的「權力」不一定來自你的頭銜有多大，而是看在「人脈網絡」中站在什麼位置！** 
  - 權力是透過`非契約的交換關係`來實現個人目標的能力
  - `權力`不同於`權威`，權威包含了明確授予的決策權。
  - `影響力`是個人在特定情境下對權力的運用, **權力 = 別人對你的「依賴程度」**。


---

#### 權力的來源

<style scoped>
section {
    font-size: 27px;
}
</style>

- `權力基礎`是有助於行動者獲得權力的特質
  - 基於**正式權威**的合法權力: 來自於你的「職位」與「頭銜」
    - 基於`獎懲能力`的獎賞/`強制權力`
  - **非正式權力**
    - 基於`個人地位`、`形象或聲望`的權力 
    - **魅力/人脈權**, **專家權**

---

#### 權力的社會交換

<style scoped>
section {
    font-size: 27px;
}
</style>

- 組織中的權力通常基於**社會交換**。
- 與市場交換不同，社會交換可能導致雙方資源的**不對等轉移**。
- 如果雙方反覆進行的社會交換條件不對等，其中一方就會對另一方擁有權力。

---

#### 社會交換與資源依賴

<style scoped>
section {
    font-size: 27px;
}
</style>

- 如果A控制了B所需的資源，B就會依賴A; 
- 如果A與B相互依賴，則雙方都無法控制對方

  - 如果B對A的依賴程度高於A對B的依賴程度，A就對B擁有`權力(影響力)`。

- 個人或企業可以透過減少對他人的依賴，並增加他人對自己的依賴來提升權力（權力的資源依賴觀點）。
- 資源依賴觀點也預測，**權力**將會集中在**控制關鍵資源**的人，以及其`技能`對企業不可或缺的人手中。。

----

#### Intel「Intel Inside」—— 控制關鍵資源、反轉依賴關係

<style scoped>
section {
    font-size: 27px;
}
</style>

- 1991 年之前，Intel 只是 PC 大廠（如 IBM）背後的`零組件供應商`，權力掌握在 `OEM` 手中。
- 策略：透過「Intel Inside」廣告直接建立終端消費者品牌認知，消費者主動指定要 Intel 晶片，PC 大廠反而必須採用 Intel 並分攤廣告費。
- 理論對應：
  - 「減少自己對他人的依賴、增加他人對自己的依賴」→ Intel 不再依賴單一 OEM，OEM 卻深度依賴 Intel。
  - 「權力累積於控制關鍵資源、技能不可或缺者」→ 晶片品牌成為不可或缺資源。

#### 權力的結構觀點

<style scoped>
section {
    font-size: 30px;
}
</style>
- 除了`資源依賴`之外，權力也可追溯至`組織結構`。
  - 在結構中佔據`某些職位`的人可能擁有權力。
  - 權力也可透過企業內部的`資訊網絡`與`社會關係`與結構產生關聯。。

#### Apple 與富士康 —— 不對等依賴產生權力

<style scoped>
section {
    font-size: 30px;
}
</style>

- Apple 控制品牌、設計、生態系與訂單（關鍵資源）；
- 富士康營收`高度依賴` Apple 訂單。
- 「B 依賴 A 的程度大於 A 依賴 B → A 對 B 擁有權力」：
  - Apple 在價格、品質、交期上擁有極強話語權。
- Apple 同時培養多家供應商（第二來源），進一步降低自身依賴。

#### 結構洞理論

<style scoped>
section {
    font-size: 27px;
}
</style>

- **Ronald Burt（羅納德·伯特**利用結構洞的概念來解釋`結構權力`。
  - 在網絡中，如果兩個個體（或群體）之間沒有連結，就會`存在結構洞`。
  - 當`某個個體`成為兩個個體（或群體）之間唯一的連結時，該個體就跨越了結構洞。
  
- 誰能連結互不相識的兩群人，誰就掌握最大的權力。

---

#### 結構洞理論

<style scoped>
section {
    font-size: 27px;
}
</style>

- 跨越結構洞的個體因為`控制了資訊流`而擁有權力。當原本未連結的兩個個體`直接進行互動`，從而消除了結構洞時，該`焦點人物`就會失去其權力。。
- **「只懂寫程式的工程部」** 和 **「只懂賣東西的業務部」**

  - 兩個群體之間的那道 **「鴻溝」或「斷層」**，就叫做 **「結構洞 (Structural Hole)」**
  - IF 你剛好是工程部裡最懂業務的人，同時也是業務部裡最懂技術的人
  - **你填補了這個洞：** 你變成了連接這兩個孤島的「橋樑」。**你因此獲得了「權力」：** 當業務部需要評估技術可行性，或工程部需要知道客戶真正想要什麼時，**雙方都必須「透過你」來溝通**。


---

#### 結構洞會帶來「權力」?

<style scoped>
section {
    font-size: 27px;
}
</style>

學術上稱為**仲介利益 (Brokerage Benefits)**，簡單來說有兩大超能力：

- **資訊優勢 (看得比別人遠)：** 因為你同時混兩個不同的圈子，你能得到「不重複的資訊」。當別人只知道 A 圈子的八卦時，你已經知道 B 圈子的情報，你能把兩邊的想法結合，產生最具創意的點子。
- **控制優勢 (成為必經之路)：** 因為 A 和 B 沒有直接連線，他們要合作、交易或交換資源，都**必須經過你**。你掌握了「誰能認識誰」以及「資訊怎麼傳遞」的控制權。

#### 利豐集團（Li & Fung）—— 跨越結構洞的興衰

<style scoped>
section {
    font-size: 27px;
}
</style>

- 全球知名的`跨國供應鏈管理公司`，專門為全球的零售商和品牌管理服飾、鞋類、玩具等消費品的生產與出口貿易，
- 興起：利豐長期作為西方零售商與亞洲工廠之間的`「唯一連結」`，跨越雙方資訊不對稱的結構洞，靠控制資訊流獲取權力與利潤（漁翁得利）。
- 衰落：2010 年代後，網際網路、快時尚（Zara）與`電商`讓買主與`工廠`直接对接，結構洞被消除 → 利豐的`仲介權力`與利潤空間萎縮，最終重整、私有化。
- 理論對應：「跨越結構洞者因控制資訊流而擁有權力」；「當結構洞被消除，焦點人物便失去權力」——此案例完美印證兩張投影片。

#### 組織成功與管理權力

<style scoped>
section {
    font-size: 27px;
}
</style>

- 管理者需要`權力`才能取得成功。
- 然而，管理者行使的權力不一定會帶來組織的成功。
- 每位管理者都扮演著`代理人`的角色，而權力會加劇`代理問題`。。

#### 權力是一把雙面刃


- 管理者`累積權力`對企業有利（有害），如果
  - 管理者與其下屬（上級）之間的`代理問題嚴重`
  - 企業的環境相對穩定（不穩定）。

---

#### 正式權力的分配

<style scoped>
section {
    font-size: 27px;
}
</style>

- 一個關鍵的管理議題是如何在組織內分配**正式權力**。

  - 如果要有效地運用權力，其分配應該基於個人所擁有的**知識**。
  - 除了知識之外，企業在分配正式權力之前，還應該考慮`個人的利益`是否與`企業的利益`一致。
  - 另一個考量因素可能是該個體預計會在企業`待多久`。
  - 企業還應該考慮權力接收者對權力的重視程度。

- 企業或許可以提供更多的正式權力而非更高的薪水，以降低離職率。。

#### 文化

<style scoped>
section {
    font-size: 27px;
}
</style>

- 文化是一套`共享的價值觀`、`信念與規範`，會影響員工的偏好與行為。

  - 文化為組織成員間的`隱性契約`設定了脈絡。
  - 當`正式契約`與`手冊`無法發揮作用時，文化可作為適當行為的`非正式指標`。
- 文化，就是公司裡 **「大家心照不宣的做事方式」**，它是沒有寫在員工手冊上，但每個人都知道該遵守的「潛規則」。。

----

#### 文化輔助正式控制

<style scoped>
section {
    font-size: 27px;
}
</style>
- 文化可以限制管理者的自由, **你看不見它，但它無所不在**。
- 如果文化規範支持企業的策略，文化也能協助管理者, 

  - **水質(文化)決定了魚(公司) 的狀態**, 這缸水（文化）是充滿毒素、互相猜忌的，再兇猛的魚（優秀員工）也會生病、想逃跑；
  - 如果這缸水是溫暖、互相支持的，平凡的魚也能長得很好
- 文化、結構、實務做法與人員共同影響企業的績效。。

------

#### 文化與績效

<style scoped>
section {
    font-size: 27px;
}
</style>

- 文化常被用來解釋為何兩個在其他方面相同的企業（國家）似乎表現不同。
- 要使文化有助於實現競爭優勢
  - 文化必須是`獨特`且`難以模仿的`，並且
  - 文化必須對企業`有價值`。

- 如果文化很容易被複製，競爭對手就會複製成功企業的文化，這樣就不會有相關的競爭優勢。
- 文化可能很容易被記錄和描述，但無法輕易被複製。

-----

#### 文化與績效

<style scoped>
section {
    font-size: 27px;
}
</style>

- 文化對企業有價值，是因為
  - 透過`補充`正式控制系統來降低監督成本，以及
  - 透過塑造個人偏好以符合企業目標。

- 降低`談判與協商成本`。
- 無須使用明確的手段即可達成合作。

----

#### 文化與正式契約

<style scoped>
section {
    font-size: 27px;
}
</style>

- 文化可以將個人的目標與行為和企業的目標對齊.
- 文化比正式契約能更有效地控制個人活動。
- 擁有`正確的文化`，可以降低監督成本並將投機行為降至最低。

-----

#### 文化與合作

<style scoped>
section {
    font-size: 27px;
}
</style>

- 文化創造了`相互強化`的規範，使自利的行動者參與互惠的活動。

  - 根據無名氏定理 (Folk Theorem)，合作是許多可能結果中的一種。

- `降低內部交易成本`：當內部充滿信任且價值觀一致時，就不需要制定厚厚的員工手冊和繁瑣的審批流程，組織運行效率極高。。
- `合作的文化`塑造了個人的期望，使其預期他人會合作，並解決困難的代理問題。

- `知行合一（Alignment）`：文化不是口號，而是與 KPI、晉升機制和資源分配掛鉤。。

- `文化與策略適配`：當內部脈絡完美支撐了外部策略時，好結果就會自然發生

#### Netflix：「自由與責任」與極致坦誠
- **內部脈絡 / 文化**：Netflix 的文化脈絡建立在 **「極高的人才密度」** 之上。
  - 他們取消了一切繁文縟節（沒有休假天數限制、沒有差旅審批流程），並推崇「極致的坦誠」（Radical Candor）。內部脈絡默認：只要你是成年人且為了公司好，你就應該擁有最大的決策自由，但同時必須承擔極高的績效責任。

- 帶來的好結果：這種反傳統的內部脈絡極大地降低了組織內部的**交易與監督成本**。它賦予了員工極高的敏捷性與決策速度，使 Netflix 能夠屢次成功自我顛覆（從 DVD 租賃到串流媒體，再到原創內容霸主），並持續產出現象級的影視作品。

#### Toyota（豐田汽車）：「持續改善」與賦權第一線
- 內部脈絡 / 文化：豐田模式（The Toyota Way）的核心內部脈絡是 **「持續改善」**（Kaizen） 與 **「尊重人性」**。
- 在傳統製造業中，停止生產線是嚴重的失誤；但在豐田，任何一位第一線員工只要發現瑕疵或異常，都有權利且有義務拉下頭上的「安燈」（Andon）繩索，直接停止整條生產線，且不會受到懲罰，反而會得到團隊的協助來解決根本問題。
- 帶來的好結果：這種賦權基層的文化脈絡，造就了豐田舉世聞名的精益生產系統（TPS）。它讓豐田在生產品質、成本控制和庫存管理上長期領先全球，使其成為全球利潤最高、韌性最強的汽車製造商之一。

#### 文化與慣性

<style scoped>
section {
    font-size: 27px;
}
</style>

- 文化的缺點是它可能會`阻礙變革`。
- 當企業的策略與環境契合時，文化規範可以是一項資產。
- 當企業必須在面臨快速環境變遷的情況下適應以求生存時，文化可能會拖累績效。



#### 對文化的警惕


- 文化會以多種方式造成`慣性`
  - 任期較長的高階主管是在不同條件下學習其工作的，可能無法`應對變革`。
  - 企業內的`權力基礎`可能會受到變革的威脅，導致這些群體阻礙變革。
  - 組織常規可能存在`保守偏誤`。

#### Nokia —— 文化阻礙激進變革

<style scoped>
section {
    font-size: 27px;
}
</style>

- 研究（Vuori & Huy）指出 Nokia 內部存在`共享恐懼`文化：
  - 高層威壓、中層隱藏壞消息、報喜不報憂，Symbian 的問題長期被掩蓋。
  - 資深主管在`舊條件`下成功、權力基礎（硬體/Symbian 部門）受變革威脅而阻撓變革、組織慣例保守偏誤。
- 結果：2007 年 iPhone 崛起後迅速衰落，2013 年將手機事業賣給 Microsoft。
- 理論對應：`文化可能拖累績效`的慣性機制全部命中。

#### 動態價格競爭

<style scoped>
section {
    font-size: 30px;
}
</style>

- 價格競爭可視為一個`動態過程`, 企業`今天的決策`將影響其`自身`以及`競爭對手`未來的行為  

- 動態競爭也可能發生在`非價格競爭`方面，例如產品品質, 售後服務。

#### 動態模型與靜態模型

<style scoped>
section {
    font-size: 30px;
}
</style>

- 動態模型能夠回答靜態模型無法回答的問題（例如：什麼決定了價格競爭的`激烈程度`？）  

- 在靜態模型中看似`短期利潤`的行為，在動態模型中往往帶來長期的負面效應

---

#### 動態模型適用的情境

<style scoped>
section {
    font-size: 30px;
}
</style>

- 靜態模型無法解釋：在沒有`正式合謀`的情況下，企業如何能將價格`長期`維持在競爭水準之上 

- 在某些情況下，即使只有少數幾家企業，也可能引發激烈的價格競爭  

- 動態模型有助於探究此類情形

---

#### 合作定價

<style scoped>
section {
    font-size: 30px;
}
</style>

- 若價格`持續`高於競爭水準，而企業並未採取`顯性的合作行為`，則稱為合作定價。

- 當競爭對手預期將在未來多期中會反復互動時，可能缺乏發動`價格戰`的動機。
  - 若一家企業降價，短期內其市場份額可能上升；
  - 但一旦競爭對手開始報復，市場份額將回到原狀，而價格卻已降低，導致雙方處境更糟。

---

#### Tit-for-Tat Pricing 以牙還牙定價

<style scoped>
section {
    font-size: 30px;
}
</style>

- 當兩家企業在`多期中`相互競爭時，**以牙還牙策略**可能使合作定價成為可能  
  - 企業首先採取合作定價（如維持高價）；此後，每一輪都模仿競爭對手上一輪的定價行為
  - 若對手降價，則自己也降價報復；若對手維持高價，則自己也繼續合作維持高價。
  
- Robert Axelrod在其著作《合作的演化》中描述了一場重複`囚犯困境`的電腦競賽  
  - 儘管在任何單場比賽中，`以牙還牙`策略最多只能與其他策略打平，但它在所有比賽中綜合得分最高

---

#### 可樂戰爭（Coca-Cola vs. Pepsi）——合作面和平的成功範例

<style scoped>
section {
    font-size: 30px;
}
</style>

- 兩家百年對抗，但`終端售價`幾乎永遠相同、策略互相回應。
- 雙方都把戰火導向`廣告`、`包裝`與`通路`，而非削價
  - 因為彼此都知道降價會被瞬間跟進，先降者只會壓縮自己的利潤。
- 這正是以牙還牙的嚇阻效果：「你降我必降」的可信威脅，反而維持了價格和平

---

#### OPEC 1985–86 油價崩跌——「懲罰式」以牙還牙的成功範例

<style scoped>
section {
    font-size: 30px;
}
</style>

- 成員國長期`超額生產作弊`，沙烏地阿拉伯转而採取以牙還牙策略，故意增產砸價，懲罰作弊者。
  - 油價從每桶約 28 美元暴跌到 8 美元，懲罰結束後回升並穩定在 18 美元左右，合作紀律得以重建。
  - 2014–16 年劇本重演：沙國拒絕減產，以低價懲罰美國頁岩油與作弊成員，之後才重回協調減產。
- 教訓：成功的 TFT 是「**短暫、明確的懲罰＋懲罰後的原諒**」，而不是無限期報復。

- 可樂戰爭, OPEC 展示了以牙還牙「用得對」可以恢復合作

----

#### 加油站 Edgeworth 價格循環——肉眼可見的以牙還牙

<style scoped>
section {
    font-size: 30px;
}
</style>

- 在美國、加拿大許多城市，油價呈現規律的`「鋸齒循環」`：一家加油站降價搶客，對手跟進並再壓低，價格一路跌到接近成本；直到某家嘗試漲價，若同業跟進，價格才回到高檔
- 學術文獻直接將這種動態描述為「**一連串**以牙還牙的價格序列」（tit-for-tat price series）。
- 美國 FTC 也曾專門研究這種循環是否構成`默契合謀`。
- 這是日常生活中最赤裸的以牙還牙定價：降价必被跟進、漲价需試探默契

----

#### Amazon vs. Walmart——演算法時代的即時以牙還牙

<style scoped>
section {
    font-size: 30px;
}
</style>

-  Amazon 的`動態定價演算法`會自動追蹤、匹配甚至壓過對手網站的價格。
- 當雙方都部署`「你降我跟」`的機器人，價格回應從數週壓縮到數分鐘；
  - 嚇阻效果更強，但一旦誤判，價格戰也爆發得更快、更難踩煞車。

#### 加油站與超市貨架

<style scoped>
section {
    font-size: 30px;
}
</style>

-  超市等零售業一旦某品牌降價，競爭者跟進後，整體價格水準會被`永久拉低`，誰也拿不回利潤。
- 街角加油站同理：一家降價，對面幾小時內跟進；最後雙方回到原價時，市場價格已`永久下移`
   ——這是以牙還牙`「雙輸」`面的日常示範。

#### 平台補貼戰：滴滴快遞、美團饿了么京東

<style scoped>
section {
    font-size: 30px;
}
</style>

-  2015–16 年`網約車`補貼戰及後續價格戰，被研究認為高度符合`囚犯困境`與 Bertrand 競爭的預測。
-  2025 年`京東`高調殺入外送，引發`美團、饿了么、京東`「0 元奶茶」即時零售大戰，補貼規模以百億計。學術論文以重複囚犯困境分析美團–饿了么雙占，稱之為「自我毀滅式價格戰」；平台商家也公開警告價格戰 。
- 教訓：**當第三方新玩家入場（京東、Aldi），舊的以牙還牙合作均衡就會崩解**——因為新玩家不買舊默契的帳。

#### 以牙還牙與誤讀（Misreads）

<style scoped>
section {
    font-size: 30px;
}
</style>

- 當可能`誤讀對手行動`時，以牙還牙策略的表現可能不如`更寬容`的策略  
- 企業可能只能觀察到對手的`標價`，有的時候無法得知其`實際成交價 ` 
- `標價下調`可能被誤認為是價格戰，而實際上未必如此
- 一次誤讀就可能導致企業在合作與非合作行為之間**反復切換**  
- 額外的誤讀會使行為模式更加混亂  
- 存在誤讀可能的情況下，**延遲反應**可能優於立即反應

#### 合作定價長久持續條件

<style scoped>
section {
    font-size: 30px;
}
</style>

- `合作定價`得以長久持續的條件：
  1. 無名氏定理（The Folk Theorem）
  2. 市場結構與合作定價
  3. 相關的結構性條件

#### 無名氏定理（The Folk Theorem）

<style scoped>
section {
    font-size: 30px;
}
</style>

- 只要`貼現率`足夠大 (愈`重視未來`的報酬，而愈不重視眼前的收益)，任何介於`邊際成本`與`壟斷價格`之間的價格均可維持。
  - `較大的貼現率`使合作定價帶來的`年金現值`更大，從而更有利於達成合作結果。
  - 只要玩家有足夠耐心，幾乎任何「合理」的報酬分配都可以透過某種策略組合在長期成為均衡結果。

- 「大家都知道、但不知道誰最先提出」的數學結果，在學術界就被稱為"folk theorem" —— 類似於民間故事（folk tales）：流傳廣泛，但作者不詳。

---

#### 市場結構與合作定價 

<style scoped>
section {
    font-size: 30px;
}
</style>

- 實現合作定價可能依賴於某些`市場結構條件`  
- 例如：    
  - 市場集中度    
  - 影響反應速度和檢測滯後的因素    
  - 企業間的不對稱性    
  - 買方對價格的敏感度

---

#### 市場集中度與合作定價

<style scoped>
section {
    font-size: 30px;
}
</style>

- 合作定價更可能出現在`高度集中的市場`中維持著
- 在`高度集中市場`中，降價帶來的收入損失更大, 獲取新客戶的潛在收益更小
  - 典型企業能獲得更高價格帶來的更大份額收益； 
  - 由於初始市場份額較大，想要偏離合作的短期收益較小
  - 收益-成本比更傾向於維持高價格



`企業數量越多`，`協調`一個`聚焦策略`就越困難  

- 市場集中度與合作定價可持續性之間的關係，是`反壟斷政策`的重要考量因素

---

#### 反應速度與合作定價

<style scoped>
section {
    font-size: 30px;
}
</style>

- 若競爭對手價格削減能被**即時被發現**，合作定價越容易維持  
- 影響反應速度的因素包括：
  - 識別價格變動的`滯後時間`；
  - 與競爭對手`互動的頻率`；
  - `難以確定`是哪家競爭對手在降價；
  - 難以區分銷量下降是由`競爭對手降價`還是`需求減少`所致。

---

#### 相關的結構性條件

<style scoped>
section {
    font-size: 30px;
}
</style>

- 訂單的塊狀性（Lumpiness） 
- 銷售交易資訊的可獲得性  
- 買家數量  
- 需求條件的波動性

---

#### 訂單的塊狀性

<style scoped>
section {
    font-size: 30px;
}
</style>

- 訂單的`塊狀性`（Lumpiness of orders）：大筆、不連續、間歇性的方式出現
  - 當訂單具有塊狀性時，企業之間並非持續面對彼此的定價決定。
  - 報復可能延後很久才發生（因為下一個大訂單可能幾年後才出現），使得：
    - 降價的短期收益（贏得當前大訂單）變得非常誘人；
    - 報復的長期成本（未來利潤損失）因時間折現而顯得較小。

- 例如：飛機機身製造、船舶建造中的大額訂單  
  - 訂單間隔拉長，使得降價帶來的收益相對于對手報復的成本更具吸引力

---

#### 交易資訊的可獲得性

<style scoped>
section {
    font-size: 30px;
}
</style>

- 當交易公開時，偏離合作定價的行為比交易私密時更容易被發現. 
  - 例如：`汽油銷售`的交易價格易於觀察，而`飛機銷售`則不易觀察  

- `定制化產品`偏離合作定價更難被察覺；`標準化產品`則相反  

- 複雜交易比簡單交易更容易導致誤讀

---

#### 需求波動性 

<style scoped>
section {
    font-size: 30px;
}
</style>

- 當`市場需求波動劇烈`且企業只能觀察自身銷量時，價格戰更難被識別  

- 需求下降可能被誤認為是競爭對手降價  

- 在固定成本較大的行業中，壟斷價格波動劇烈，使協調變得困難

---

#### 促進合作定價的實際做法 
<style scoped>
section {
    font-size: 30px;
}
</style>

- 企業可通過以下方式促進合作定價：  
  - 價格領導（Price leadership）  
  - 提前公告價格變動   
  - 最惠客戶條款（Most favored customer claus es）  
  - 統一到岸定價（Uniform delivered pricing）

----

#### 價格領導

- 行業中的`領導者`率先宣佈價格變動，其他（跟隨）企業隨後跟進匹配  

- 如果領導者在跟隨者偏離合作時不予報復，價格領導機制可能崩潰



#### 提前公告價格變動

<style scoped>
section {
    font-size: 30px;
}
</style>

- 提前公告可以降低對手壓低價格的不確定性 

- 若對手偏離合作定價，企業還可撤回原定價格變動

---

#### 最惠客戶條款（Most Favored Customer Clauses）

<style scoped>
section {
    font-size: 30px;
}
</style>

- 最惠客戶條款允許`買方`享受賣方給予任何客戶的`最低價格`  

- 雖然該條款看似對買方有利（任何客戶獲得的降價都會使最惠客戶受益），但它同時也抑制了價格競爭



#### 統一到岸定價 

- 當運輸成本顯著時，定價方式可分為： 
  - 統一離岸價（FOB）定價，或統一到岸定價  
  - 採用統一到岸定價時，對降價行為的報復可做到`精准打擊`，有效遏制企業偏離合作定價

### 什麼是荷蘭病（Dutch Disease）？

<style scoped>
section {
    font-size: 25px;
}
</style>

- `荷蘭病`是經濟學中的經典概念，描述的是**單一產業異常繁榮，反而對整體經濟造成結構性傷害**的現象。該詞源於荷蘭的經歷：1959年荷蘭在北海發現大型天然氣田後，天然氣出口帶來大量外匯，導致荷蘭盾大幅升值，反而削弱了製造業的出口競爭力，引發去工業化

其核心傳導機制有三：

- **貨幣升值效應**：出口橫財帶來外匯湧入，本幣升值，其他出口產業的價格競爭力下降。
- **排擠（資源移動）效應**：資本、人才與土地被吸入繁榮部門，其他產業面臨人才流失與成本上升。
- **支出效應**：繁榮帶來的收入推高國內物價與資產價格，進一步壓縮其他產業的生存空間。

- 最終結果是經濟`單一化`：高度依賴單一產業，波動性大增；一旦繁榮結束，經濟便因缺乏其他支撐產業而格外脆弱。

#### 臺灣與韓國半導體產業的荷蘭病之爭

<style scoped>
section {
    font-size: 27px;
}
</style>

- AI 熱潮下，半導體成為台、韓經濟的核心引擎，但`半導體版荷蘭病`的警告也隨之而來。2026年7月，韓國銀行（韓國央行）明確警告：韓國經濟過度集中於半導體，可能出現其他產業萎縮、危機時易崩潰的類似“荷蘭病”情況

- 出口與增長高度依賴單一產業。 2025年臺灣半導體相關出口占出口總額高達`61.35%`。若將資通產品與電子零元件合併計算，2025年上半年兩者占總出口比重達`70.8%`。台積電一家就占全球晶圓代工市場逾`六成`，臺灣電子零元件出口約占總出口近五成，高度依賴單一產業。台積電對臺灣GDP的貢獻更達約十分之一。韓國方面，半導體約占其總出口的20%左右
  - 經濟過度集中于單一繁榮的產業，人才、資本與土地被排擠: 半導體業以高薪吸走工程人才與資金，傳統產業與服務業面臨人才荒；新竹、台南、高雄等科學園區周邊房價被科技薪資推高，正是`支出效應`的體現，即特定部門推高整體價格。


---
<style scoped>
section {
    font-size: 25px;
}
</style>
- 潛在結構性風險  
   - 半導體產業推動了整體經濟增長，但這種增長並未均勻惠及全社會。經濟增長的速度超過了平均工資的增速，導致財富差距擴大。例如，臺灣最富裕的 20% 與最底層的 20% 之間的財富比率，已從 30 年前的 4.9 倍上升至如今的 6.1 倍。
   
- 韓國銀行指出，半導體`獨食型`繁榮無法帶動整體經濟均衡增長，獨佔資金與人力的現狀反而會加劇整體經濟的波動性。
  - 韓國在晶片榮景背後還暗藏內需疲弱等結構性隱憂。
  

- 學者點名。經濟學家 García-Herrero 將臺灣對半導體的高度依賴形容為`死于成功`（dying of success），視為潛在的荷蘭病案例. 諾丁漢大學的研究也認為，臺灣經濟已顯現可歸因於半導體業崛起的`荷蘭病`症狀. 
  - `死于成功”`非指產業本身的衰退，而是指單一產業的過度繁榮可能掩蓋並催生宏觀經濟的結構性脆弱（如產業單一化、貧富分化），最終可能反噬整體經濟的長期健康發展。這一概念常被用於提醒政策制定者在享受特定產業紅利時，需注重經濟多元化和包容性增長。

- 外部市場依賴
  - 半導體產業對外部市場的高度依賴，以及對諸多電子零部件進口的依賴 
  - 臺灣韓國被外部需求綁架：2026年上半年GDP成長率14.15%，反映出口結構變動帶來的壓力 
  - 全球半導體需求波動直接影響臺灣經濟穩定

- 產業成功本身不是問題，但過度依賴單一成功產業會使整個經濟體變得脆弱，失去應對外部衝擊的能力。

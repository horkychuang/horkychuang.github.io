#### 代理關係與績效衡量 （Agency and Performance Measurement）

<style scoped>
section {
    font-size: 30px;
}
</style>

- `企業`如何促使`員工`努力推進公司戰略?
- **委託–代理**框架有助於回答這一問題。  
  - 框架內容：`委託人（如企業）`雇傭`代理人（如管理者）`採取行動 ，這些行動會影響委託人的收益。

---

#### 代理問題（Agency Problems）

<style scoped>
section {
    font-size: 30px;
}
</style>

- `委託人`獲得的收益 = 代理人行動所創造的`價值` - 支付給`代理人的報酬程度`。  
  - 代理人關注的是：所獲報酬 - 自身付出的努力成本。  
  - 若缺乏`有效機制`協調雙方利益，衝突便會產生。

---

#### 激勵與契約（Incentives and Contracts）

<style scoped>
section {
    font-size: 30px;
}
</style>

- 若能簽訂`完全契約（complete contracts）`，代理問 題易於解決；
  - 但現實中，代理人的某些行為不可觀測（**“隱藏行動”，hidden action**）； 

  - 代理人可能掌握委託人無法獲知的資訊（**“隱藏資訊”，hidden information**）；

- **信息不對稱**：代理人通常擁有比委託人更多的資訊  

  - 因此，基於不可觀測`行為`或`資訊`的契約無法被有效執行。。


----

#### 三種核心表現形式

<style scoped>
section {
    font-size: 27px;
}
</style>

- `努力程度不一致（道德風險)`
   - 在契約簽訂後，由於委託人無法完美監控代理人的實際行動（資訊不對稱），代理人為了自身利益最大化，選擇「隱性偷懶」或降低努力程度，從而損害委託人的利益。
  - `代理人`因為拿固定工資，多幹少幹收入差別不大. 
    - 餐廳經理在老闆不在時可能提前打烊、敷衍顧客
  - 購買全險的車主事故率高於只買基本險的車主; 
  - 失業救濟可能延長失業期間, 部分人可能「自願失業」以領取救濟

-----
**企業軟體外包開發（固定總價合約）**
<style scoped>
section {
    font-size: 27px;
}
</style>
- 企業（委託人）花 100 萬委託外部團隊（代理人）開發一套內部系統，合約規定固定總價，並設定了最終交付日期。

- 外包團隊為了最大化這個專案的利潤（或為了同時接更多案子），暗中採取了「降低努力程度」的行為：
  - 將資深工程師抽調去接其他利潤更高的案子，改由缺乏經驗的初級工程師主導。
  - 省略耗時的自動化測試環節與程式碼審查。
  - 使用現成但不完全契合的開源套件湊數。
- 因為企業客戶通常`不懂技術（資訊不對稱）`，在驗收初期很難看出「程式碼品質差」或「架構脆弱」，直到系統上線後頻繁崩潰、難以擴充，問題才全面爆發。

- 當你的努力程度無法被完美監控，且報酬與努力脫鉤時，『偷工減料』就會成為代理人最理性的利潤最大化策略。
----
<style scoped>
section {
    font-size: 25px;
}
</style>

- `風險偏好不一致`
  - 代理人可能承擔`過多`或`過少`的風險
    - 華爾街交易員用別人的錢冒險：贏了拿獎金，輸了最多丟工作
    - CEO可能過於保守，因為冒險失敗的個人代價太高

- 委託人（股東/銀行）： 偏好 `「長期穩健」`。
  - 股東雖然希望獲利，但通常持有分散的投資組合，且銀行一旦因巨額虧損破產，股東將面臨毀滅性打擊（或面臨嚴格的監管懲罰）。
- 代理人（交易員/高管）： 偏好 `「短期高風險」`。
  - 因為他們的薪酬結構類似金融學的「買權（Call Option）」：賭贏了，拿走巨額年終獎金；賭輸了，最多只是被解僱，不需要自掏腰包賠償公司的巨額虧損（下行風險有限，上行收益無限）。

- 當代理人『贏了拿大獎、輸了不用賠』時，他們就會理性地選擇對公司最危險的賭博，因為風險由別人承擔，利潤卻歸自己所有。
----
<style scoped>
section {
    font-size: 25px;
}
</style>

- `信息不對稱` (逆向選擇)
  - 代理人知道委託人不知道的資訊，並利用這種`優勢謀私利`. 
    - 例如：基金經理知道真實業績歸因，但投資者不知道
  - **檸檬市場**: 這是`逆向選擇(selection selection)`導致**市場失靈**的經典案例, 資訊不對稱可能導致高品質產品被低品質產品驅逐出市場. 
    - **高風險人群**：覺得保費便宜（風險高，超划算）→ **積極投保**, `如果` 保險公司設定`「平均保費」`. 
    - **高風險借款人**：覺得利率可以接受（反正可能不还）→ 積極借款, `如果` 銀行設定`「平均利率」`
- 當你把門檻（或價格）設得讓『好人』覺得不划算時，最後願意留下來的，往往全是準備坑你的『壞人』。

#### 安然公司（Enron）醜聞 - 最經典的代理問題失控案例

<style scoped>
section {
    font-size: 25px;
}
</style>

- 2001年美國能源巨頭安然公司破產，成為歷史上最大的企業欺詐案之一
- 代理問題表現：
  - `信息不對稱`：管理層通過複雜的特殊目的實體（SPE）`隱藏債務`、`虛增利潤`
  - `利益衝突`：董事會和審計師要麼不理解、要麼不願意揭露真相
  - `風險偏好扭曲`：高管用股東和債權人的錢進行高風險投機
- 結果：
  - 公司崩潰，數萬員工失去工作和養老金
  - 股東損失數百億美元
  - 成為透明度缺失導致代理問題失控的經典案例 
- 教訓： `資訊不對稱`讓代理人得以在委託人不知情的情況下，把整家公司變成謀取私利的工具。

#### 華爾街金融危機（2008）

<style scoped>
section {
    font-size: 27px;
}
</style>

- 2008年全球金融危機，數百萬美國人失去房子、工作和積蓄
- 代理問題表現：
  - `風險不對稱`：華爾街交易員用`銀行資本（儲戶和股東的錢）`做高風險交易
  - `激勵扭曲`：贏了拿巨額獎金，輸了由納稅人買單
  - `道德風險`：金融機構`大而不能倒`，預期政府會救助
  - "如果你有一個體系，讓人們用別人的錢去承擔風險，贏了自己拿走利潤，輸了由別人承擔損失——你會得到完全可以預見的災難性結果。

<style scoped>

</style>

- 企業常採用以下手段將員工利益與雇主利益對齊：    
  - 獎金（Bonuses） 
  - 加薪（Raises） 
  - 利潤分享（Profit sharing） 
  - 股票期權（Stock options） 
  - 未來晉升機會（Future promotion） 
  - 解雇威脅(Threat of firing)。

#### 顯性激勵契約（Explicit Incentive Contracts）

<style scoped>
section {
    font-size: 27px;
}
</style>

- 契約可基於`績效指標`制定，例如： 
  - 銷售額 
  - 銷售增長率 
  - 產量 
- 員工的努力程度取決於`邊際收益`，而非薪酬的絕對水準； 
- 企業可通過提高傭金比例、降低底薪來提升利潤； 
- 最優底薪甚至可能為負（如特許經營中加盟商需向總部支付費用）。

---

#### 績效薪酬的弊端（Downside of Pay-for-Performance）

<style scoped>
section {
    font-size: 27px;
}
</style>

- `績效衡量`往往存在誤差； 
  - 若員工`風險厭惡`，績效薪酬合同需提供`風險溢價`； 
  - 當一方風險厭惡、另一方風險中性時，風險應由風險中性方承擔； 
  - 若員工需同時承擔多項任務（如銷售與客戶服務），可能只專注于回報更高的任務； 
- 常見績效指標`難`以全面反映`員工整體表現`。。

**富國銀行（Wells Fargo）假帳戶醜聞**
<style scoped>
section {
    font-size: 27px;
}
</style>
- 銀行設定了一個極度明確、可量化的契約：
  - 員工若能讓單一客戶持有 `8 項以上`的金融產品（如存款、信用卡、貸款，稱為「Going for Gr-Eight」），就能獲得豐厚獎金與晉升機會。

  - 結果：員工為了達標拿獎金，選擇了最簡單的路徑：在`客戶完全不知情`的情況下，偷偷開設了超過 350 萬個「假帳戶」和「假信用卡」來湊數。最終導致銀行被重罰數億美元、高層下台，品牌聲譽遭受毀滅性打擊。

- 當你只為`可量化的數字`付錢時，員工就會想辦法『操縱數字』，而不是創造真正的價值。」

#### 激勵機制（Incentive Mechanisms）

<style scoped>
section {
    font-size: 30px;
}
</style>

除顯性契約外，企業還可採用： 

- 隱性契約（Implicit contracts） 
- 主觀評估（Subjective evaluation） 
- 晉升錦標賽（Promotion tournaments） 
- 解雇威脅（Threat of termination）。

---

#### 隱性激勵契約（Implicit Incentive Contracts）

<style scoped>
section {
    font-size: 27px;
}
</style>
- 隱性激勵契約（Implicit Contract）：沒有寫在紙上、無法由法院強制執行，但雙方心照不宣的「長期默契」。它不依賴法律條款，而是基於「重複博弈」與「聲譽機制」（我現在好好做，預期你未來會好好待我）。

- 許多崗位缺乏完美的績效衡量標準； `隱性契約`可通過主管的主觀評估實現； 
- 為使隱性契約有效，企業應： 
  - 確保員工認為企業始終按契約精神行事； 
  - 在全公司範圍內一致應用績效標準； 
  - 在不可預見情況下無法兌現預期獎勵時，及時與員工溝通。。

---
**Costco（好市多）的高薪與低離職率策略**
<style scoped>
section {
    font-size: 27px;
}
</style>
- `傳統零售業（顯性契約）`：支付最低工資，依賴嚴格的打卡監控、防盜警報和標準化流程。預期員工只是「螺絲釘」，流動率高是常態。
- `Costco（隱性契約）`：支付遠高於市場平均的薪資（時薪通常比同業高 30-40%），提供極佳的醫療福利，且絕大多數高階主管都是從基層員工內部提拔。
  - Costco 的全職員工`第一年離職率`僅約 6%（傳統零售業通常高達 40%~60% 以上）。
  - 員工:提供超額的忠誠度、主動服務與高生產力，公司會長期照顧我，不輕易裁員，並給我穩定的職涯發展。
  - 企業: 我現在多付你錢，預期你會長期留下，這將大幅降低我的招募與訓練成本，並透過你的優質服務帶來更高的客單價與極低的商品損耗。

#### 主觀績效評估（Subjective Performance Evaluation）

<style scoped>
section {
    font-size: 27px;
}
</style>

- 一些企業採用`360度同行評審`； 
  - 收集所有與你合作的人（老闆、平級同事、下屬，甚至客戶）對你的反饋
- 有些採用`固定評分池（fixed pool of points）`分配給員工； 
  - 「固定總量的分數」（例如 100 分），必須把這些分數分配給不同的對象、專案或評估指標 ， 防止評審者當濫好人。
- `按曲線評分`（grading on a curve）可緩解`評分壓縮`（ratings compression）問題； 
  - 不看「絕對分數」，只看「相對排名」。根據整體群體的表現來分配成績（通常強制符合常態分佈）。
- 企業可通過限制員工接觸決策者的機會，減少`影響行為`（influence activity）。

---
**軟體工程師的「程式碼行數」陷阱 vs. 主管的「主觀綜合評估」**
<style scoped>
section {
    font-size: 25px;
}
</style>
- 不依賴冰冷的客觀數據（如銷售額、產量、點擊率），而是由主管或評審者根據`專業判斷`與`日常觀察`，對員工的「工作品質、團隊貢獻、解決複雜問題的能力」進行質化、綜合性的評分。
  - 因為「能被輕易量化的，往往不是最重要的」。許多`高價值行為`（如指導新人、跨部門協調、避免潛在危機、長期技術架構優化）無法被寫進簡單的公式裡。
  - 某科技公司曾嘗試用「寫出的程式碼行數」或「修復的 Bug 數量」來客觀考核工程師。結果：工程師開始寫冗長無用的程式碼來湊行數，或故意先寫出有 Bug 的程式碼，再自己修復它來衝業績。
  - 改為進行主觀綜合評估。主管會綜合觀察並判斷：
    - 「他是否主動重構了難以維護的舊程式碼？（雖然這週沒產出新功能）」
    - 「他是否在會議中幫助初級同事解決了卡關？」
    - 「他設計的架構是否為公司節省了未來的伺服器成本？」
- 這些無法被系統自動抓取的「隱性貢獻」，由具備專業知識的主管透過主觀判斷來給予績效加成。

#### 晉升錦標賽（Promotion Tournaments）

<style scoped>
section {
    font-size: 30px;
}
</style>

- 高層職位數量少於基層，因此並非所有員工都能晉升； 
- 晉升錦標賽可有效抑制員工偷懶（shirking）； 
- 員工會積極採取行動以提高晉升概率； 
- 在某一級別勝出者可進入下一級別競爭；`贏家通吃`（winner-take-all）的獎勵機制可抵消評分壓縮問題。

---
<style scoped>
section {
    font-size: 27px;
}
</style>
- 公司有 `5 位`能力相近的副總裁，但只有 `1 個` CEO 的缺額。CEO 的薪酬與權力是副總裁的 3 倍以上。公司不會去精確計算每個人「今年為公司多賺了 exactly 多少錢」，而是觀察這 5 個人誰的綜合表現相對最好。
  - `正面效應（激發極限努力）`：為了贏得那個巨大的獎品，5 位副總裁都會拼命加班、主動承擔高難度專案，展現出遠超日常的努力水準。
  - `負面效應（破壞行為 Sabotage）`：當競爭過於激烈時，候選人發現「提升自己」太難，於是轉向`拉低對手`。例如：故意隱瞞關鍵資訊、在老闆面前貶低同事的專案、拒絕跨部門資源共享，甚至互相使絆子。

- 不看你絕對做了多少，只看你`贏過`多少人；巨大的晉升獎品能激發極限努力，但也可能誘發不擇手段的內部互鬥。

---
#### 解雇威脅（Threat of Firing）

<style scoped>
section {
    font-size: 27px;
}
</style>
- 效率工資（Efficiency Wages） 與 解雇威脅（Threat of Firing） 是一體兩面的機制：企業故意支付「遠高於市場水準」的工資，創造出一個極具價值的職位。
  - 因為這份工作太難得，員工一旦因偷懶或違規被解雇，將面臨巨大的收入損失（失業懲罰）。這種「害怕失去高薪工作」的恐懼，會迫使員工進行強大的自我監督。
- 當企業支付的工資`高於`市場水準時，解雇構成有效懲罰； 
- **失業者儲備**（unemployed pool）對在職員工形成激勵； 

  - 勞動力市場中**具備工作能力、正在積極尋找工作，但尚未與工作職位配對成功的群體總和**

- 當監督困難時，**效率工資 efficiency wages**尤為有效；

  -  企業會故意支付高於市場均衡水準的工資（效率工資），這會導致勞動力供給大於需求，從而**人為創造並維持一個「失業者儲備」**。

- 非工資福利（如保險、培訓）可提升崗位價值，增強激勵效果。。

**亨利·福特（Henry Ford）的「5 美元日薪」與社會部審查**
<style scoped>
section {
    font-size: 27px;
}
</style>
- 當時汽車組裝線的工作極度單調、高壓且危險，市場平均日薪約為 `2.34 美元`。福特面臨災難性的員工流動率（每年高達 370%），導致招募與訓練成本居高不下，生產線經常停擺。
  - `實施效率工資`：福特驚世駭俗地將日薪`提高到 5 美元`，並將工作時間從 9 小時縮短至 8 小時。
  - `啟動解雇威脅`：高薪不是白給的。福特成立了「社會部（Sociological Department）」，派調查員到家裡審查員工的私人生活。如果發現員工酗酒、賭博、家裡髒亂或不贍養家人，就會被立即解雇。
- 結果：因為 5 美元的工資在當時是夢幻級的待遇，員工極度害怕失去這份工作。流動率暴跌， absenteeism（曠工）大幅減少，員工自發地提高工作節奏與專注度。福特的生產力大幅提升，利潤甚至足以覆蓋這筆龐大的加薪成本。
- 給你遠超市場的薪水，不是因為你值得，而是為了讓你`極度害怕失去這份工作`，從而心甘情願地自我鞭策、不敢偷懶。

#### 團隊中的激勵（Incentives in Teams）

<style scoped>
section {
    font-size: 27px;
}
</style>

- 為充分發揮團隊生產的效益，獎勵應基於團隊整體產出； 
- 但團隊績效衡量下，個人行動的收益由全體共用； 
- 個體可能不願採取對團隊有益但個人成本高的行動； 
- 每個成員都缺乏充分激勵——即“搭便車問題”（free rider problem）。


#### 團隊激勵的解決方案（Solutions）

- 控制團隊規模，使其足夠小； 
- 讓團隊成員長期共事，促進合作； 
- 設計團隊結構，使成員能相互監督。

#### 職業關切與長期雇傭（Career Concerns and Long-Term Employment）

<style scoped>
section {
    font-size: 25px;
}
</style>

- 員工會採取提升其未來勞動力市場價值的行動； 
- 典型例子包括：投資銀行家、基金經理、職業運動員； 
  - 年輕的共同基金經理有強烈動機避免相對業績不佳； 
  - 擁有長期良好記錄的管理者更能承受某一年的業績下滑； 
  - 有時，職業聲譽帶來的激勵甚至強於績效薪酬（如職業運動員）。。

- 隨著CEO臨近退休，其薪酬與公司業績的關聯度通常更高； 
  - 老將運動員的合同常包含條款：若未達成特定客觀標準，則減薪； 
- 可能頻繁跳槽的員工更傾向於積累**通用型人力資本**（general-purpose human capital），而不願投資於**企業專用技能（firm-specific skills）**； 
- 企業需對員工獲取專用技能給予回報，例如： 
  - 提供長期雇傭保障； 
  - 承諾隨時間推移提供更陡峭的薪酬增長曲線。
